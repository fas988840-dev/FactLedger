# لماذا لم تُنشر صفحة GitHub Sponsors؟ — التشخيص وخطة الإصلاح

## الدليل من لوحة التحكم (لقطة 19 أكتوبر)
صفحة «مستويات الراعي» في لوحة Sponsors تظهر:
- عنوان: «ابدأ بالمكافآت» مع زر أخضر **«تابع إلى محرر الطبقة»** وخيار «تخطَّ هذه الخطوة».
- مستويان محددان: $5 شهريًا (شارة الراعي) و$10 لمرة واحدة (صيحة على تويتر).

هذا يعني أن خطوة المستويات **ما زالت داخل محرر الإعداد ولم تُستكمل/تُنشَر من اللوحة**
بصورتها النهائية. لذلك يبقى الرابط العام يعيد التوجيه 302 ولا تظهر صفحة كالتي تظهر
للحسابات المنشورة، بينما يعرض المستودع رابط التبرع الخارجي فقط.

## ما لا أستطيع فعله من جهتي
إكمال اللوحة يحدث داخل حساب GitHub المسجَّل الدخول (جلسة متصفح المؤسس). لا الواجهة
البرمجية ولا رمز الوصول repo/workflow يملك صلاحية نشر ملف Sponsors أو إعداد الدفعات.

## خطوات المؤسس داخل اللوحة (بالترتيب)
1. افتح: https://github.com/sponsors/fas988840-dev/dashboard
2. من «مستويات الراعي» اضغط الزر الأخضر «تابع إلى محرر الطبقة».
3. راجع المستويين ($5 شهري / $10 مرة واحدة) ثم «حفظ»/«نشر» إن ظهر.
4. أكمل أي خطوة تالية يطلبها المعالج: تفاصيل الملف الشخصي ← الأهداف ← المراجعة.
5. ادخل «دفعات» (Payouts) وتأكد أنه لا توجد خطوة دفع/ضريبة/تحقق ناقصة معلَّقة.
6. أرسل/انشر الملف إن ظهر زر «Submit for review» أو «Publish».
7. أرسل لي لقطة لأي شاشة تتوقف عندها وسأرشدك سطرًا سطرًا.

## ما تم من جهتنا
- `.github/FUNDING.yml` صحيح، وزر Sponsor يعرض رابط FUNDING/DONATE.md.
- روابط Solana Pay فورية ($5/$10/$25/$100) تعمل دون انتظار GitHub.
- متابعة رسمية على التذكرة #4872016 تطلب النشر أو تحديد المانع الدقيق.
- حالة المشروع: CI ناجح، CodeQL ناجح، تنبيهات الفحص مفتوحة = 0.

## قاعدة الصدق
حتى يضغط المؤسس «نشر/إرسال» داخل اللوحة أو يرد GitHub بمانع آخر، لا يدّعي أحد أن
الصفحة منشورة. أول ما تتغير الحالة من 302 إلى 200 سنعلنها بنفس اليوم.
