# بحث التبرعات والرعاية والمنح — 19 أكتوبر 2026

## الخلاصة التنفيذية

لا يوجد في الأدلة المراجعة راعٍ ملتزم أو منحة جديدة مقبولة أو تبرع وارد مثبت. هذا بحث لمسارات مناسبة، وليس تمويلًا محصّلًا. لم تُرسل رسائل ولم يُوقّع أي شيء بالمحفظة ولم تُقدم طلبات.

## ترتيب المسارات

### 1. Giveth — صفحة تبرعات للمشروع (أولوية عملية)

الدليل الرسمي:
- https://docs.giveth.io/createproject
- https://docs.giveth.io/projectverification

وثائق الإنشاء تتيح تعريف المشروع واختيار شبكة وعنوان استقبال، وتشمل Solana؛ لا يُستخدم عنوان Solana على شبكة EVM. الإنشاء والنشر يتطلبان جلسة المالك وربط المحفظة وقد يتطلبان توقيعًا داخل الموقع الرسمي. التحقق وGIVbacks لهما طلب ومراجعة منفصلان، ولا يضمن النشر تبرعات أو matching.

الملاءمة: الجزء المفتوح المصدر، الأدلة القابلة لإعادة الإنتاج وتوثيق المطورين قد يشكل منفعة عامة. القبول غير محسوم ويخضع لشروط المنصة. يجب فصل التبرع الطوعي عن بيع تقارير أو منح مزايا تجارية.

الإجراء التالي: تحقق أولًا هل توجد صفحة FactLedger منشورة بالفعل لتجنب التكرار، ثم أكملها من حساب المالك. البريد يحوي استفسارًا سابقًا لـGiveth بتاريخ 17 أكتوبر ومتابعات يوم 18 أكتوبر؛ هذا لا يثبت إنشاء صفحة.

### 2. Kraken Open-Source Grants — متابعة الطلب القائم فقط

الدليل الرسمي: https://www.kraken.com/features/grants

البرنامج ينظر في Bitcoin وEthereum وLightning وMonero وعملات عامة أخرى وRust، ويسمح بالتواصل عبر البريد بمواد المشروع. Solana ليست ضمان أهلية أو أولوية. لم يُتحقق من مبلغ ثابت أو موعد نهائي جديد من الصفحة.

يوجد طلب $10,000 ومتابعات سابقة، آخر متابعة ظهرت في البحث بتاريخ 13 أكتوبر. لا ترسل طلبًا جديدًا مكررًا. استخدم السلسلة الحالية عند الحاجة مع رابط التغييرات التقنية، واذكر أن النشر الجديد لم يُتحقق منه بعد.

### 3. GitHub Sponsors — استكمال الحساب لا إعادة إعداد المستودع

https://github.com/sponsors/fas988840-dev/dashboard

ملف FUNDING موجود. آخر فحص للرابط العام أعاد تحويلًا للحساب؛ جاهزية W-8 لا تثبت النشر أو تفعيل الدفعات. المطلوب استكمال ما تعرضه لوحة المالك أو انتظار قرار التذكرة #4872016، لا دفع رسوم لوسيط أو تكرار إيميلات الدعم.

### 4. Superteam Agentic Engineering — متابعة عند إعادة فتح التقديم

https://superteam.fun/earn/grants/agentic-engineering/

فُتحت صفحة المصدر مباشرة، وليس مقتطف البحث فقط. تعرض «Open / Global / 200 USDG» لكن زر التقديم يقول **Applications Paused**. لذلك لا تُسجل فرصة متاحة للتقديم الآن. تصف الصفحة دفعتين 50%/50% وKYC وإيصالات اشتراكات برمجة بقيمة إجمالية $200؛ ليست منحة تشغيل عامة بقيمة $10,000.

### 5. استبعاد فرص غير مطابقة

- https://superteam.fun/earn/grants/build-for-breakpoint : التقديم متاح في الصفحة لكنه **UK only**، فلا يُنصح لمؤسس مقيم بالرياض دون أهلية مثبتة.
- https://solana.org/grants-funding : مسارات منفعة عامة ومراحل عمل، لكن طلب FactLedger السابق مرفوض لعدم تقدم المشروع بما يكفي؛ حضّر أدلة تقدم واستخدام خارجي قبل طلب جديد.
- Vaultline: دعوة تدقيق لا إثبات منحة نقدية أو قبول؛ لا تخلطها بطلب Superteam النقدي.
- DoraHacks: الرد السابق يقول إنها منصة تقديم وليست جهة community grant مباشرة لهذا الطلب.

## عرض رعاية جاهز للمراجعة — غير مرسل

**هدف مقترح، وليس مبلغًا محصلًا:** $500 لدورة تحسين لمدة شهر.

توزيع تقديري: $200 لخدمات RPC، $100 للاستضافة والمراقبة، $200 لاختبارات الأدلة وأمثلة REST/MCP. راجع عروض أسعار المزودين قبل الالتزام. المخرجات: سجل تحسينات، اختبارات قابلة للتشغيل، تقرير مصروفات، ودليل تحقق من النشر. لا تعد بمنح دقة أعلى أو توصيات استثمارية أو استخدام غير مثبت.

نص إنجليزي مقترح:

> FactLedger is an MIT-licensed, read-only Solana wallet-intelligence API and MCP server. We are seeking a small, milestone-based sponsorship to improve reliability, reproducible evidence fixtures, and developer documentation. The API currently passes 226 local tests; its dependency audit is clean. The dashboard production dependency audit is also clean, while five high-severity development-tool findings remain documented. The latest repaired branch has not yet been verified on the production host. We can share the repository, a concrete one-month scope, and a transparent budget. Would this fit your open-source infrastructure support program?

لا يُرسل هذا النص جماعيًا. اختر جهة تستفيد من RPC أو MCP المفتوح المصدر، وتحقق من سياسة الرعاية وقناة التواصل الرسمية. لم يُحدد في هذا البحث راعٍ وافق على الدفع.
